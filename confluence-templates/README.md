# Shared Confluence templates

One shared set lives in the Engineering space; teams publish into their own spaces.
Engineering managers jointly own these (see CODEOWNERS). Edit here, review by PR, then
copy the change into the Confluence template so the two stay in step.

| Template | Used by |
|---|---|
| [design-doc.md](design-doc.md) | Jira Automation: Epic → design doc |
| [postmortem.md](postmortem.md) | Jira Automation: Incident → postmortem |
| [release-notes.md](release-notes.md) | `release-notes.yml` page layout |
| [sprint-report.md](sprint-report.md) | `sprint-report.yml` page layout |
