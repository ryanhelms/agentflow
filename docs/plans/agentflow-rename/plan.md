GitHub redirects ordinary web and Git traffic after a rename. Actions and reusable workflows using the old slug can fail even when pinned to a SHA. A historical workflow can also call the old slug internally after its caller has switched URLs. Keep the retired slug available for redirects and use a newly tested pin.
