                      Plugins

                      Plugins add event handlers and permission rules to Agentflow. They run in the console daemon on this computer, for every repository it serves.

                      A plugin runs as you and is not sandboxed.

                      A process plugin is a program on this computer: it can read your files and use the network. The permissions on a card limit what a plugin does through Agentflow, not what its program does by itself. Install only plugins whose code you trust.
