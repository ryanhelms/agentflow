---
name: work
description: List work from the configured task provider
---
Call agentflow_my_work and show the key, summary and status for each task. Asana lists open tasks in the configured project across assignees.
Offer `/agentflow:start KEY` for the one I pick.

CLI equivalent: `agentflow work`. The `agentflow` command is on your Bash PATH (the plugin's `bin/`); the first run installs the latest verified release.
