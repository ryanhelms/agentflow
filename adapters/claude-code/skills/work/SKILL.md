---
name: work
description: List work from the configured task provider
---
Call devflow_my_work and show the key, summary and status for each task. Asana lists open tasks in the configured project across assignees.
Offer `/devflow:start KEY` for the one I pick.

CLI equivalent: `devflow work`. The `devflow` command is on your Bash PATH (the plugin's `bin/`); the first run installs the latest verified release.
