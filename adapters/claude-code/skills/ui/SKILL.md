---
name: ui
description: Open the local devflow repository console to inspect providers, preview configuration edits and review repository activity
argument-hint: "[--no-open] [directory]"
---
Run `devflow ui $ARGUMENTS` from the intended worktree. Keep the process running while the developer uses the browser. The printed URL grants access to this local session. Keep it on the developer’s machine. The developer reviews and approves a configuration PR in the console.
