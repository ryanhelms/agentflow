# Grok CLI

`settings.json` → `.grok/settings.json` in the repo. Instructions come from `AGENTS.md`
(or the Grok instructions file that `agentflow install --client grok` links to it).
Grok CLI implementations and their config paths differ; check against the version Nscale
standardises on and adjust `internal/install` if needed. Enforcement relies on git hooks and CI.
